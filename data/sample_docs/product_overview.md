# Acme Cloud — Product Overview

Acme Cloud is a managed platform for deploying and scaling web applications.

## Core products

- **Acme Compute**: autoscaling containers with per-second billing.
- **Acme Storage**: object storage with versioning and lifecycle rules.
- **Acme DB**: managed Postgres with automated backups every 6 hours.

## Regions

Acme Cloud currently operates in `us-east-1`, `eu-west-1`, and `ap-south-1`.
Customer data remains in the selected region unless cross-region replication is enabled.
