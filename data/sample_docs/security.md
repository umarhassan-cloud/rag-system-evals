# Acme Cloud — Security & Compliance

## Encryption

- Data in transit uses TLS 1.2+.
- Data at rest is encrypted with AES-256.
- Customer-managed keys (CMK) are available on Enterprise plans.

## Access control

Acme supports SSO via SAML 2.0 and OIDC.
Role-based access control (RBAC) includes Owner, Admin, Developer, and Viewer roles.
API keys can be scoped per project and rotated without downtime.

## Compliance

Acme Cloud maintains SOC 2 Type II attestation.
HIPAA Business Associate Agreements (BAA) are available for Enterprise customers in `us-east-1` only.
Pen tests are performed annually by an independent firm; executive summaries are available under NDA.

## Incident response

Security incidents are triaged within 15 minutes for Enterprise and 1 hour for Pro.
Customers are notified of confirmed breaches affecting their data within 72 hours.
